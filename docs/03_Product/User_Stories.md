# 1. Customer User Stories

# Account Management

## US-CUST-001: Customer Registration

**User Story**

As a customer,  

I want to create an account,  

so that I can purchase products and book services.

### Acceptance Criteria

- Customer can register using mobile number.

- OTP verification is required.

- Customer profile is created after successful registration.

- Customer can update personal information.

Priority:

High

---

## US-CUST-002: Customer Login

As a customer,  

I want secure login access,  

so that I can access my account safely.

Acceptance Criteria:

- Login through mobile OTP.

- Login through email/password.

- Invalid login attempts are handled.

- User session is maintained securely.

Priority:

High
